This repository documents the skills and projects I completed while pursuing my Master of Science in Data Analytics (Data Engineering specialization). The program focuses on real-world data competency across core areas such as:

 - Data engineering fundamentals, including data flow and system design
 - Data modeling and how data is structured for analytics and pipelines
 - ETL/ELT pipeline development, transformation, and integration
 - Data transformation and analytics-focused programming/scripting (including Python)
 - Data management, governance concepts, and data quality considerations
 - Building scalable and reliable data workflows to support decision-making
 - Data analytics application of engineering solutions aligned to business needs
 - Iterative problem-solving and delivery of working data artifacts/projects

These topics emphasize building practical, job-relevant knowledge—connecting data engineering foundations to how data solutions are designed, built, transformed, and delivered for real analytics outcomes.
